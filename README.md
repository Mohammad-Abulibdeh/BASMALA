# BASMALA | بسملة 🔬🤖

**بسملة** روبوت/مساعد علمي تفاعلي لمتحف أو معرض علوم. بيستقبل الزوّار، بيحكي معهم بالصوت (عربي وإنجليزي)، وبيشرحلهم التجارب العلمية: الاكتشاف، التفسير، طريقة التنفيذ، المبدأ العلمي، والنتيجة المتوقعة. بيعتمد على الذكاء الاصطناعي (Google Gemini) لفهم أسئلة الزائر والرد عليها بطريقة طبيعية.

في نسختين بالمستودع:
- **`robot/`** — النسخة اللي بتشتغل على **Raspberry Pi** مع حساسات وسيرفو (الروبوت الفعلي).
- **`interface/`** — نسخة بواجهة ويب للعرض.

> 🔑 المفتاح السرّي (Gemini API key) **مش محفوظ بالكود**. لازم تحطّه كمتغيّر بيئة قبل التشغيل (اقرا تحت).

## 🧠 شو بيعمل المساعد

1. **استقبال الزائر:** في نسخة الروبوت، 3 حساسات ألتراسونيك (يمين/وسط/يسار) بتكشف لما حدا يقرب، والسيرفو بيلف راس الروبوت باتجاهه، وبتضوّي LED.
2. **الاستماع:** بياخد صوت الزائر ويحوّله نص (Speech Recognition) بالعربي أو الإنجليزي.
3. **فهم النية (Intent):** بيحلّل سؤال الزائر عبر Gemini (مع خطة احتياطية بسيطة إذا الـ AI مش متوفر) — بيعرف إذا الزائر بدّو تجربة معيّنة، أو قائمة التجارب، أو سؤال عام.
4. **الرد:** بيجاوب من بيانات التجارب (ملف Excel/JSON) وبصوت عبر **Text-to-Speech** (gTTS).
5. **بيانات التجارب:** كل تجربة فيها: الاسم، الاكتشاف (Discovery)، التفسير (Explanation)، التنفيذ (Action)، المبدأ (Principle)، والتوقع (Expectation).

مثال على تجربة من البيانات: **شدّ السطح للماء (Water Surface Tension)** — ليش مشبك الورق بيطفو على سطح الماء رغم إنه أثقل منه.

## 🔌 الدارة (نسخة الروبوت)

### القطع
| القطعة | العدد | ملاحظات |
|---|---|---|
| Raspberry Pi | 1 | بيشغّل `basmala_science_assistant.py` |
| حساس ألتراسونيك HC-SR04 | 3 | يمين / وسط / يسار |
| سيرفو موتور | 1 | بيلف راس الروبوت |
| LED | 2 | إضاءة/تنبيه |
| مقاومات لمقسّم جهد ECHO | — | لحماية بنات الـ Pi من 5V |

### التوصيلات (ترقيم BCM)
| القطعة | الطرف | GPIO (BCM) |
|---|---|---|
| السيرفو | Signal | **13** |
| LED 1 | + | **21** |
| LED 2 | + | **24** |
| حساس الوسط (زاوية 110°) | TRIG / ECHO | **4** / **17** |
| حساس اليسار (زاوية 180°) | TRIG / ECHO | **5** / **27** |
| حساس اليمين (زاوية 0°) | TRIG / ECHO | **18** / **25** |

> ⚠️ خرج ECHO بالـ HC-SR04 جهده 5V، وبنات الـ Raspberry Pi بتتحمل 3.3V بس. لازم **مقسّم جهد** (مثلاً 1kΩ/2kΩ) على كل خط ECHO. حساب المسافة: `المسافة = زمن النبضة × 34300 / 2` سم.

## 🚀 التشغيل

### نسخة الروبوت (Raspberry Pi)

```bash
cd robot
pip install -r ../requirements.txt
export GEMINI_API_KEY="ضع-مفتاحك-هنا"     # على ويندوز: set GEMINI_API_KEY=...
python3 basmala_science_assistant.py
```

### نسخة الواجهة

```bash
cd interface
export GEMINI_API_KEY="ضع-مفتاحك-هنا"
python basmala_science_assistant.py
```

بتجيب مفتاح Gemini مجاناً من [Google AI Studio](https://aistudio.google.com/app/apikey).

> نسخة الواجهة بتحتاج مكتبات الصوت والـ AI، بس من غير مكتبة `RPi.GPIO` (لأنها للـ Raspberry Pi). على كمبيوتر عادي، النسخة اللي فيها GPIO رح تطلب تعديل بسيط لتعطيل جزء الحساسات.
